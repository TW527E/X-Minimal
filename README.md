# X 極簡

把 X 的時間線、側欄和閱讀介面調成自己順手的樣子。這是我平常自己在用的 Tampermonkey 腳本，設定介面採繁體中文，支援 X 新舊兩套版面。原始碼採 MIT 授權。

**這是個人自用專案。** 我會依自己的使用需求和時間決定是否處理 issue、功能請求與 PR，回覆、修正和持續維護都沒有時程承諾。遇到問題可以回報，附上瀏覽器、腳本版本、X 頁面和重現方式，方便我有空時查看。

## 安裝

1. 在瀏覽器安裝 [Tampermonkey](https://www.tampermonkey.net/)。
2. 在 [Greasy Fork](https://greasyfork.org/zh-TW/scripts/604326) 安裝 X 極簡。若使用其他 X 主題擴充套件，先暫停它，避免樣式重疊。
3. 重新整理 X，打開左側「更多」選單裡的「介面設定」，或從 Tampermonkey 選單選「X 極簡設定」。窄視窗的入口在底部分頁列。

主要在 Vivaldi 與 Chromium 驗證。X 的新版介面會分批推出，頁面改版後可能需要更新腳本。macOS 的 Vivaldi／Chrome 可使用同一份腳本，Safari 的實機相容性仍待驗證。

## 做了哪些改動

功能靈感來自 [Minimal Theme for Twitter / X](https://github.com/typefully/minimal-twitter)。這個版本以獨立 userscript 實作，加入背景、玻璃材質、媒體與備份功能。Typefully 推廣與排程整合省略。

| 功能 | 可以做什麼 |
| --- | --- |
| 時間線與側欄 | 調整主欄寬度、置中、框線和貼文分隔線。左側導覽和右側推薦欄可獨立貼邊。導覽可依寬度收合，懸浮展開時保持圖示位置。 |
| 精簡介面 | 隱藏廣告、推薦追蹤、訂閱卡、指定導覽項目、貼文計數、Grok 與聊天浮窗。可預設進入「正在跟隨」，另有專注寫作和自訂 CSS。 |
| 背景與玻璃 | 選擇本機圖片或 HTTPS 圖片網址，調整填滿方式、位置與壓暗程度。時間線和側欄／浮窗可各自設定實色、毛玻璃或 Liquid Glass。 |
| 透明介面的配色 | 隨背景選擇深淺文字，也可手動指定。發文與行內回覆的工具列跟著配色更新，媒體控制、按讚狀態和連結保留各自的用途色。 |
| 磁吸游標 | 預設關閉，可在「顯示效果」開啟。可貼合連結、按鈕和選單，文字區顯示文字游標。影片只對底部控制列吸附，拖曳進度條和音量滑軌時滑塊會跟隨。 |
| 媒體下載 | 從貼文操作列依序下載原圖或最高可用畫質的 MP4，全部放在瀏覽器下載目錄。記住已成功下載的檔案，再按會略過，按住 Shift 可重抓。按鈕直接顯示進度、部分完成與失敗狀態。下載紀錄可逐筆移除或全部清空。X 更換網頁 API 時，會改用公開的嵌入資料來源下載。 |
| 分享連結 | 貼文分享選單可直接複製不含追蹤參數的 FixupX 連結，複製後選單自動關閉，也能用方向鍵選到。可在「媒體下載與分享」關閉這個項目，或隱藏原本的「複製連結」。 |
| 影片音量 | 記住播放器音量，並可另外開啟音量平衡。三次方滑桿方便微調低音量，平衡處理在本機執行。 |
| 設定備份 | 匯出／匯入 JSON，或自選 Google Drive／WebDAV 同步外觀、背景、音量及下載紀錄。匯入的檔案含有自訂 CSS 或外部背景網址時會先提醒；其他裝置同步來的自訂 CSS 要確認後才套用。 |

## Liquid Glass 的做法

WebGL 折射改編自 [tw527e.zip](https://github.com/TW527E/tw527e.zip)，包含折射邊緣、色散和高光。時間線的畫布只涵蓋可見區域，側欄、頂列、浮窗、發文與回覆區使用各自合適的材質範圍。發文和回覆的輸入區、工具列共用同一塊玻璃。

效能不足、WebGL 失敗或背景圖片無法取樣時會退回毛玻璃。瀏覽器不支援模糊，或系統偏好減少透明度與高對比時，會使用實色。輕量模式可手動關閉折射，設定頁也會顯示自動降級的狀態和原因。

## 儲存、下載與同步

設定與下載紀錄平常存放於 Tampermonkey，同一瀏覽器設定檔中的 X 帳號會共用。圖片網址由瀏覽器向該圖片主機載入。媒體下載使用登入後的 X 網頁 API 和 X CDN，需要 Tampermonkey 的下載權限。網頁 API 失效或未登入時，會向 `cdn.syndication.twimg.com` 讀取公開貼文的媒體資訊；不公開的貼文無法使用這個備用來源。檔名和儲存位置仍受瀏覽器下載設定影響。

跨裝置同步預設關閉。啟用時資料會送到你填入的 WebDAV 或你自行部署的 Google Apps Script，詳見 [跨裝置同步設定](x-minimal-sync-guide.md)。GitHub 和 Greasy Fork 之間的同步只負責發佈腳本，不涉及個人設定或下載紀錄。

## 發佈紀錄

GitHub 的 `main` 分支是發佈來源。推送更新過版號的 `x-minimal.user.js` 後，GitHub 的 push Webhook 會通知 Greasy Fork 匯入腳本。Greasy Fork 的功能說明來自同一分支的 `greasyfork.md`。

- **1.12.1** 隱藏右側欄後，右欄的搜尋列會留在畫面右上角，空間不足時才收起；開啟「透明搜尋列」時搜尋列使用 Liquid Glass。可用「隱藏右欄搜尋列」一併隱藏。探索頁的搜尋列和分類標籤改為同一塊玻璃，不再疊成兩層。
- **1.12.0** 設定視窗改成和 X 新版設定頁相同的樣式：左側分類目錄、上方搜尋，下拉選單改為單選列，下載紀錄移到獨立頁面。窄視窗先列出分類，點進去再顯示該頁，按返回回到列表。「介面設定」入口移到左側「更多」選單裡，新舊介面都會出現在原本「設定」的下方，可用方向鍵選取；點開後選單會自動收起。看大圖或頁面還在載入時，畫面上不再出現懸浮的設定按鈕。「更多」在側邊導覽中固定顯示，避免隱藏後找不到設定入口。
- **1.11.0** 同步可略過這版不認得的設定，新設定在你改動前不會上傳，不會讓舊版裝置停止同步。來自其他裝置的自訂 CSS 需要確認，匯入設定前也會提醒風險。同步連線改在設定頁內填寫，密碼欄位會隱藏字元，並新增「測試連線」。下載紀錄可移除與清空，同步時也會一併移除。下載按鈕顯示進度與失敗狀態，X 更換 API 時會自動改用備用來源。設定頁改為分類目錄，FixupX 項目可以關閉，複製後自動收起選單並支援方向鍵，新舊介面都會顯示游標與鍵盤所在位置。舊版介面隱藏右側欄時，導覽列與時間線不再被推到畫面最右邊。窄視窗的底部分頁列加入「介面設定」按鈕，隱藏的項目不再留下空位；設定視窗在窄螢幕可用滾輪橫向切換分類，透明背景時也維持足夠的不透明度。看大圖時同樣會隱藏觀看次數。舊版介面的發文按鈕改為圖示與文字並排，不再把「Post」字樣擠到按鈕下方。選單與浮動視窗疊在淺色圖片上時維持較高的不透明度，深色模式下文字也清楚。減少捲動與播放影片時的重新計算。磁吸游標改為預設關閉。Google Drive 配套程式在資料未變時不再下載整個同步檔，需重新部署才會生效。
- **1.10.4** 分享選單新增「複製 FixupX 連結」，並可隱藏原本的複製項目。
- **1.10.3** 首次正式公開發佈，補上專案連結、作者及跨裝置同步說明。
- **1.10.2** 修正發文和行內回覆工具列的圖示，使其跟隨透明時間線的配色設定。
- **1.10.1** 統一貼文頁行內回覆的輸入區和工具列背景。
- **1.10.0** 新增媒體下載紀錄、跳過已下載項目，以及 Google Drive／WebDAV 跨裝置同步。
